# docs/jira/

Handoff documents produced by the Jira implementation pipeline (see the root `README.md`).

Per ticket:

- `<KEY>-spec.md` — specification (from `/jira-spec`)
- `<KEY>-plan.md` — implementation plan (from `/jira-plan`)
- `<KEY>-review.md` — review (from `/jira-review`)

These are committed on the ticket's feature branch so they appear in the pull request
alongside the code.
